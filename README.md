# Volume Calculator 📏

A simple Python tool to calculate the volume of a rectangular prism with full unit support, powered by the **Pint** library.

## Features

* **Smart Volume Calculation:** Specifically designed for rectangular shapes.
* **Multi-Unit Support:** Input dimensions in meters, centimeters, inches, feet, or any other length unit supported by [Pint](https://pint.readthedocs.io/).
* **Standardized Output:** Automatically normalizes all inputs and provides the final result in **cubic meters (m³)**.
* **Error Prevention:** Eliminates manual conversion mistakes and unit-related calculation errors.

## About Pint

This project uses the **Pint** library to manage physical quantities. Pint allows for:
1. **Mathematical consistency:** Units are tracked throughout the calculation.
2. **Seamless conversion:** Easy handling of mixed units (e.g., multiplying centimeters by inches) and converting them to a metric standard unit.
